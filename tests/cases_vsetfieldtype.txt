# vector set-field-type (leaf + pipeline step): two conversion engines.
# Leaf/fallback translates SetFrom-style (declared source type drives
# coercion, incomplete-parse/overflow/subtype warning set, inconvertible
# values warn then drop the whole feature); a step directly following a
# GeoJSON read is absorbed into the read as a schema override (raw JSON
# reinterpretation, silent clamps, %.17g strings) with mutex/required
# validation skipped, unless the terminal is GDALG. Conversion warnings
# only surface when the writer pulls features (unguessable driver and
# unconsumed stream outputs stay silent); warning replay follows the
# terminal's pull count.
