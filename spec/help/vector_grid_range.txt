Usage: gdal vector grid range [OPTIONS] <INPUT>... <OUTPUT>

Create a regular grid from scattered points using the difference between the minimum and maximum values in the search ellipse.

Positional arguments:
  -i, --input <INPUT>                                      Input vector datasets [may be repeated] [required]
  -o, --output <OUTPUT>                                    Output raster dataset (created by algorithm) [required]

Common Options:
  -h, --help                                               Display help message and exit
  --json-usage                                             Display usage as JSON document and exit
  --config <KEY>=<VALUE>                                   Configuration option [may be repeated]
  -q, --quiet                                              Quiet mode (no progress bar or warning message)

Options:
  -f, --of, --format, --output-format <OUTPUT-FORMAT>      Output format
  --co, --creation-option <KEY>=<VALUE>                    Creation option [may be repeated]
  --extent <xmin>,<ymin>,<xmax>,<ymax>                     Set the target georeferenced extent [4 values]
  --resolution <xres>,<yres>                               Set the target resolution [2 values]
                                                           Mutually exclusive with --size
  --size <xsize>,<ysize>                                   Set the target size in pixels and lines [2 values]
                                                           Mutually exclusive with --resolution
  --ot, --datatype, --output-data-type <OUTPUT-DATA-TYPE>  Output data type. OUTPUT-DATA-TYPE=UInt8|Int8|UInt16|Int16|UInt32|Int32|UInt64|Int64|CInt16|CInt32|Float16|Float32|Float64|CFloat32|CFloat64 (default: Float64)
  --crs <CRS>                                              Override the projection for the output file
  --overwrite                                              Whether overwriting existing output dataset is allowed
  -l, --layer, --input-layer <INPUT-LAYER>                 Input layer name [may be repeated]
                                                           Mutually exclusive with --sql
  --sql <statement>|@<filename>                            SQL statement
                                                           Mutually exclusive with --input-layer
  --bbox <BBOX>                                            Select only points contained within the specified bounding box
  --zfield <ZFIELD>                                        Field name from which to get Z values.
  --zoffset <ZOFFSET>                                      Value to add to the Z field value (applied before zmultiply) (default: 0)
  --zmultiply <ZMULTIPLY>                                  Multiplication factor for the Z field value (applied after zoffset) (default: 1)
  --radius <RADIUS>                                        Radius of the search circle
                                                           Mutually exclusive with --radius1
  --radius1 <RADIUS1>                                      First axis of the search ellipse
                                                           Mutually exclusive with --radius
  --radius2 <RADIUS2>                                      Second axis of the search ellipse
  --angle <ANGLE>                                          Angle of search ellipse rotation in degrees (counter clockwise) (default: 0)
  --min-points <MIN-POINTS>                                Minimum number of data points to use (default: 0)
  --min-points-per-quadrant <MIN-POINTS-PER-QUADRANT>      Minimum number of data points to use per quadrant (default: 0)
  --max-points-per-quadrant <MAX-POINTS-PER-QUADRANT>      Maximum number of data points to use per quadrant (default: 2147483647)
  --nodata <NODATA>                                        Target nodata value (default: 0)

Advanced Options:
  --oo, --open-option <KEY>=<VALUE>                        Open options [may be repeated]
  --if, --input-format <INPUT-FORMAT>                      Input formats [may be repeated]

For more details, consult https://gdal.org/programs/gdal_vector_grid.html
